# document/media/

Drop user-supplied images, screenshots, and brand assets here. They become
available via `/openpress/media/<filename>` inside the rendered cards.

For images sourced from the web, also add an entry to `SOURCES.md` before
using the image — the validator treats missing provenance as a failure.

For generated images, store the raw visual only (no embedded text) unless
the skill workflow explicitly required text inside the image.
